* Introdução

Este documento contém uma visão completa das formas de inicialização de variáveis em C++,  
incluindo suas *implicações reais de gerenciamento de memória*, *lifetime*, *storage duration*  
e todos os detalhes necessários para entender como o C++ gerencia valores e endereços.

Além disso, inclui uma seção extensa sobre *ponteiros*, desde os mais básicos até ponteiros  
para funções e membros, além de smart pointers modernos.

* Fundamentos essenciais de memória em C++[fn:1][fn:1-1][fn:2][fn:2-2][fn:2-3][fn:2-4][fn:2-5][fn:2-7][fn:2-8][fn:2-9] 

Para entender inicialização, é essencial conhecer a memória:

**Segmentos principais em um processo C++:**

1. **Text Segment (Código)**  
   - Instruções do programa compilado.

2. **Data Segment**  
   - Variáveis globais e estáticas *inicializadas*.

3. **BSS Segment**  
   - Globais e estáticas *não inicializadas* (zeradas automaticamente).

4. **Heap**  
   - Memória dinâmica via =new=, =delete= ou alocadores.

5. **Stack**  
   - Variáveis automáticas (escopo local), parâmetros, frames de função.

**Durações de armazenamento (storage duration):**

- *automatic* → variáveis locais (stack).  
- *dynamic* → via new/delete (heap).  
- *static* → globais, estáticas, singletons.  
- *thread* → específicas a threads.

* 1. Default Initialization (Inicialização Padrão)

**Sintaxe:**  
#+begin_example
int x;
#+end_example

**Comportamento:**

- Variáveis locais **não são inicializadas**.  
- Valor é **indeterminado** (garbage).  
- Leitura gera *Undefined Behavior*.

**Impacto na memória:**

- Alocada na *stack*.  
- Conteúdo é o que estiver naquele endereço.  
- Se x for global → vai para BSS e será zerado.

#+begin_src C :tangle exemplos/default_init.cpp
#include <iostream>

int main() {
    int x; // valor indeterminado
    std::cout << "Valor indeterminado: " << x << "\n";
}
#+end_src

---

* 2. Zero Initialization (Inicialização com zero)

Acontece quando:

- Variáveis estáticas/globais sem inicializador.
- Value initialization com braces.

#+begin_src C :tangle exemplos/zero_init.cpp
#include <iostream>

int x; // global → zero-initialized

int main() {
    std::cout << "Global x = " << x << "\n"; // sempre 0
}
#+end_src

**Memória:**  
- Globais → **BSS**  
- Valor inicial garantido = 0

---

* 3. Value Initialization (x{} ou T())

**3.1. Variáveis locais com chaves → inicializam com zero**

#+begin_src C :tangle exemplos/value_brace.cpp
#include <iostream>

int main() {
    int x{}; // inicializado com 0
    std::cout << x << "\n";
}
#+end_src

**Memória:** stack, valor seguro (0).

* 4. Copy Initialization (int x = 10)

#+begin_src C :tangle exemplos/copy_init.cpp
#include <iostream>

int main() {
    int x = 10; 
    std::cout << x << "\n";
}
#+end_src

**Impacto:**  
- Inicialização ocorre na stack.  
- Pode chamar construtores no caso de objetos.

* 12. Dynamic Allocation (Heap)

#+begin_src C :tangle exemplos/dynamic_new.cpp
#include <iostream>

int main() {
    int* p = new int{42};
    std::cout << *p << "\n";
    delete p;
}
#+end_src

**Memória:**  
- `new` aloca na **heap**.  
- Obrigatório chamar `delete`.

* 13. Smart Pointers (Gerenciamento Automático)

**unique_ptr**
#+begin_src C :tangle exemplos/unique_ptr.cpp
#include <memory>
#include <iostream>

int main() {
    auto p = std::make_unique<int>(42);
    std::cout << *p << "\n";
}
#+end_src

**shared_ptr**
#+begin_src C :tangle exemplos/shared_ptr.cpp
#include <memory>
#include <iostream>

int main() {
    auto p = std::make_shared<int>(10);
    auto q = p; // refcount++
    std::cout << *q << " (refcount ativo)\n";
}
#+end_src

**weak_ptr**
#+begin_src C :tangle exemplos/weak_ptr.cpp
#include <memory>
#include <iostream>

int main() {
    std::weak_ptr<int> w;
    {
        auto s = std::make_shared<int>(5);
        w = s;
        std::cout << "Dentro do escopo " << *s << "\n";
    }
    std::cout << "Após destruir shared_ptr, weak_ptr é expirado\n";
}
#+end_src

* 14. Ponteiros: Guia Completo

**14.1. Ponteiro cru básico**

#+begin_src C :tangle exemplos/pointer_basic.cpp
#include <iostream>

int main() {
    int x = 10;
    int* p = &x;
    std::cout << *p << "\n";
}
#+end_src

**14.2. Ponteiro nulo**

#+begin_src C :tangle exemplos/pointer_null.cpp
#include <iostream>

int main() {
    int* p = nullptr;
    std::cout << "Ponteiro nulo criado com segurança\n";
}
#+end_src

**14.3. Aritmética de ponteiros**

#+begin_src C :tangle exemplos/pointer_arith.cpp
#include <iostream>

int main() {
    int v[3] = {1,2,3};
    int* p = v;
    std::cout << *(p+1) << "\n";
}
#+end_src

**14.4. Ponteiros para arrays**

#+begin_src C :tangle exemplos/pointer_array.cpp
#include <iostream>

int main() {
    int v[3] = {1,2,3};
    int (*p)[3] = &v;
    std::cout << (*p)[1] << "\n";
}
#+end_src

**14.5. Ponteiro para função**

#+begin_src C :tangle exemplos/pointer_function.cpp
#include <iostream>

int foo(int x){ return x*2; }

int main() {
    int (*f)(int) = foo;
    std::cout << f(10) << "\n";
}
#+end_src

**14.6. Ponteiro para membro**

#+begin_src C :tangle exemplos/pointer_member.cpp
#include <iostream>

struct S { int x; };

int main() {
    int S::* pm = &S::x;
    S s{42};
    std::cout << s.*pm << "\n";
}
#+end_src
