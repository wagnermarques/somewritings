** Conceito de igualdade entre dois números reais
Dois números reais são iguais quando não existe nenhum outro número
real entre elas na reta real.

+ prova por contradição[fn:1]
  se 0,999... < 1

  então existe \delta > 0 tal que 0,999... + \delta = 1

  devido ao fato de que \delta - 0,999... é menor que qualquer número
  maior que 0

  então \delta <= 0, o que contradiz que \delta > 0

  portanto 0,999... = 1
